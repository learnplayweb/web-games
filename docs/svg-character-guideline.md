# 캐릭터 SVG 제작 가이드

## 목적

Web Games의 캐릭터 파츠 SVG를 제작하기 위한 기준 문서이다.

모든 SVG는 본 문서를 기준으로 작성한다.

문서에 없는 기능이나 구조는 임의로 추가하지 않는다.


----
# SVG 제작 규격

## 공통

* viewBox : `0 0 160 160`
* 모든 SVG는 중심 좌표 `(80, 80)`을 기준으로 제작한다.
* 같은 종류의 파츠는 동일한 viewBox와 기준 좌표를 사용한다.
* 디자인만 변경하고 기준 좌표와 비율은 유지한다.
* 새로운 파츠를 추가해도 JavaScript에서 위치를 다시 보정하지 않는 것을 원칙으로 한다.


## 1. Parts

* 기준 중심 : `(80, 80)`
* 제작 가이드 : 90 × 90 (x=35, y=35)
- 제작 가이드에 외곽선이 꽉 차게


## 2. Eyes

* 기준 중심 : `(80, 83)`
* 좌우 간격 : `28`
* 기준 높이 : `y = 83`

좌표

* 왼눈 : `(66, 83)`
* 오른눈 : `(94, 83)`


## 3. Mouth

* 기준 중심 : `(80, 95)`
* 최대 폭 : `12`

좌표

* 시작점 : `(74, 95)`
* 끝점 : `(86, 95)`


## 제작 원칙

* 같은 종류의 SVG는 동일한 제작 규격을 따른다.
* 기준 중심과 좌표계를 변경하지 않는다.
* SVG 수정 시 디자인만 변경하고 위치와 비율은 유지한다.
* 파츠를 교체하거나 추가해도 JavaScript에서 위치를 수정하지 않는다.
* 모든 파츠는 동일한 슬롯 구조를 재사용할 수 있도록 제작한다.

# 기본 컨셉

* 단순하고 귀여운 디자인
* 둥글고 통통한 느낌
* 날카로운 모서리 사용 금지
* 약간 찌글찌글한 실루엣 허용
* 어린이가 좋아할 수 있는 디자인
* 작은 화면에서도 형태를 쉽게 구분할 수 있어야 한다.
* 선은 크레파스나 분필 질감을 가지며 부드러운 느낌을 위해 굵게 표현

# 캐릭터 구조

캐릭터는 최대 3개의 파츠를 사용한다.

1단계

* 머리(눈,입 포함)

2단계

* 머리
* 상체(팔 포함)

3단계

* 머리
* 상체(팔 포함)
* 하체(다리 포함)

머리, 상체, 하체는 같은 재료(파츠)를 사용하여 조합한다. 
단 조합 시 크기 비율은 머리가 100%일 때, 상체와 하체는 머리의 70% 정도의 크기로 조정하여 조합한다.

---

# 얼굴

머리에는 항상 얼굴을 표시한다.

구성

* 눈 : 작은 점 2개
* 입 : 짧은 선 1개

표정은 단순하게 유지한다.

---

# 팔 / 다리

팔과 다리는

* 선 하나
* 끝에 작은 원

형태를 사용한다.

너무 길거나 복잡하게 만들지 않는다.

---

# 색상

기본 SVG는 단색으로 제작한다.

색상 시스템은 별도로 적용한다.

SVG에는 특정 색상에 의존하는 효과를 넣지 않는다.

---

# 애니메이션 대응

SVG는 애니메이션을 고려하여 제작한다.

각 파츠를 독립적으로 선택할 수 있도록 적절한 id 또는 그룹(<g>)을 사용한다.

예)

* head
* body
* legs

---

# 애니메이션 방식

SVG 내부에서 애니메이션를 구현하지 않는다.

JavaScript 또는 CSS에서 애니메이션을 적용한다.

기본 애니메이션

* 둥실둥실(상하 이동)
* 살랑살랑(좌우 기울기)

추가 애니메이션

* 머리, 상체, 하체가 서로 약간 다른 각도로 흔들림
* 각 파츠는 약간의 시간차를 두고 움직임
* 눈 깜빡임(랜덤 간격)

SVG는 위 애니메이션을 적용하기 쉬운 구조로 작성한다.

---

# 성능

* SVG는 최대한 가볍게 작성한다.
* 불필요한 path 사용 금지.
* 가능하면 circle, ellipse, rect 등을 적극 활용한다.
* path 수는 최소화한다.

---

# 스타일

* SVG 하나만 보아도 귀엽게 보여야 한다.
* 어떤 파츠끼리 조합되어도 어색하지 않아야 한다.
* 단순함을 최우선으로 한다.
* 과한 디테일은 사용하지 않는다.

---

# 구현 원칙

* 재사용 가능한 구조
* 반응형(viewBox 사용)
* JavaScript에서 쉽게 접근 가능한 구조
* 유지보수가 쉬운 구조
