# 새 게임과 효과 연결 시 프롬프트

이 프로젝트에는 게임 로직과 시각적 이펙트를 완벽히 분리한 **다층 아키텍처 기반의 효과 시스템(Effect System)**이 이미 구축되어 있습니다. 새로운 게임 화면을 개발할 때 파티클 효과(예: 콤보, 정답, 클리어 등)를 연동하려면 다음 가이드를 반드시 준수하여 코드를 작성해 주세요.

**1. 필요한 모듈 Import**
게임의 메인 스크립트 최상단에 다음 두 가지 핵심 함수를 임포트해야 합니다. (경로는 새 게임의 위치에 맞게 조절하세요.)
```javascript
// 4단계: 파티클을 실제로 렌더링하는 실행 함수
import { spawnEffect } from '../../characters/assets/effects/effects.js';

// 5단계: 사용자가 장착한 효과 중 하나를 중복 없이 랜덤으로 뽑아주는 선택 함수
import { pickRandomEquippedEffect } from '../../characters/inventory.js';
```

**2. 이벤트 라우터 (제어 타워) 구축**
게임 스크립트 내부에 게임 이벤트와 효과 시스템을 이어주는 중계 함수(`playEventEffect`)를 작성합니다. 
이 함수는 "어떤 이벤트인가?"를 판별하여, 선택 시스템에서 효과 ID를 받아 실행 시스템으로 넘겨줍니다.

```javascript
/**
 * @param {string} eventType - 이벤트 종류 (예: 'combo', 'correct', 'clear')
 * @param {HTMLElement} targetElement - 파티클이 발생할 기준점 요소 (반드시 DOM에 렌더링된 실존 요소여야 함)
 */
function playEventEffect(eventType, targetElement) {
  try {
    if (!targetElement || typeof spawnEffect !== 'function') return;

    if (eventType === 'combo') {
      const effectId = pickRandomEquippedEffect(); 
      if (effectId) {
        spawnEffect(targetElement, effectId); // 파라미터 순서 엄수: (타겟 요소, 효과 ID)
      }
    }
    // 필요에 따라 eventType 분기를 추가하여 다른 연출을 기획할 수 있습니다.
  } catch (e) {
    console.error("이벤트 효과 실행 중 에러 발생:", e);
  }
}
```

**3. 게임 메인 로직(이벤트 발생처)에 연결**
게임 로직(예: 점수 판정, 콤보 계산) 내부에서는 배열 검사나 난수 생성 같은 복잡한 코드를 절대 작성하지 마세요. 조건이 충족되면 **단 한 줄의 라우터 호출만 수행**합니다.

```javascript
// 예: 3콤보 달성 시
if (currentCombo >= 3 && currentCombo % 3 === 0) {
  // 타겟 엘리먼트는 파티클이 터질 중심 좌표를 제공할 안전한 부모 요소나 캐릭터 SVG를 넘깁니다.
  playEventEffect('combo', characterSvg);
}
```

**※ 주의 사항 (Troubleshooting)**
- `spawnEffect`의 첫 번째 인자(`targetElement`)는 반드시 화면에 렌더링되어 크기(`getBoundingClientRect()`)를 잴 수 있는 요소여야 합니다. `display: none`이거나 크기가 0인 껍데기 요소를 넘기면 파티클이 화면 좌상단(0,0)에 맺히거나 나타나지 않습니다.
- 위 구조를 준수하면 유저가 상점에서 장착한 다중 효과들이 자동으로 랜덤(직전 이펙트 제외)으로 발동됩니다. 추가적인 배열 처리나 로컬 스토리지 접근 로직을 게임 파일에 절대 작성하지 마세요.

# 정오답 연출
 써 있지 않은 사항은 임의로 하고 이후 필요하면 수정하는 것으로.
 시계 게임의 정오답 연출을 참고하여 디자인의 통일성을 유지한다.

  ## 일반 마당
    1. 정답
      정답 블록에 0.6초 간 초록 표시(시계 게임 참고)와 캐릭터 표정과 움직임 correct 세트

    2. 오답: 하트 차감 없음. 학습 모달 있음.
      오답 블록에 0.6초 간 빨강 표시, 캐릭터 표정과 움직임 wrong 세트, 동시에 캐릭터가 깜박인다(빠른 점멸). 
      > 학습 모달이 나오고 동시에 갈림길 이전 블록이 현재 블록으로, 캐릭터도 이전 위치(갈림길 이전이면 대체로 중앙이겠으나)로 롤백
      > 학습 모달 닫힌 후 게임 진행(방향 입력) 가능
      
    3. 조작 실수: 하트 차감
      캐릭터 추락(캐릭터 눈과 입 wrong 세트, 움직임 correct 세트 /추락하는 동안(1.5~2초?) 캐릭터 컨테이너가 꾸준히 회전하면 좋겠음. 예: 0~60도, 0~-60도 /블록을 밟지 못해 추락하는 것이므로 캐릭터만 추락)
      > 추락 이전 블록이 현재 블록으로, 캐릭터도 빠른 점멸과 함께 이전 위치(좌,우,중앙)로 롤백 (롤백 완료 이후면 깜박일 때도 진행 가능)


  ## 복습 마당 (추후 구현 시 참고)
    1. 정답, 3. 조작 실수: 일반 마당과 같음
    2. 오답: 하트 차감, 학습 모달 없음.
      블록과 캐릭터가 함께 추락(블록의 추락 속도가 좀 더 빠르게, 캐릭터 눈과 입 wrong 세트, 움직임 correct 세트, 캐릭터 회전)
      > 갈림길 이전 블록이 현재 블록으로, 캐릭터도 이전 위치로 롤백되고 캐릭터가 깜박이면서(빠른 점멸) 나타난다. (롤백 완료 이후면 깜박일 때도 진행 가능)
