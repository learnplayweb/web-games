클로
"불꽃 연쇄"와 "레이저 발사"의 전체 효과가 0.6초 이내에 종료되도록 animation-delay와 각 파티클의 animation-duration을 함께 조정한다. 순차 발동 느낌은 유지하되 마지막 파티클까지 시간 안에 종료되어 뚝 끊기지 않도록 한다.
이를 포함하여 이어서 응답 바람.

파티클별 animation-delay를 살짝 스태거링해서 순차 발동 느낌을 냈는데, 이 때문에 전체 종료 시점이 0.6s를 살짝 넘습니다(~0.7~0.8s).

## 2단계 — 상점에서 효과 구매
효과 목록 표시
가격 표시
구매 조건 처리
구매 후 보유 수량 증가
기존 파츠/색상 구매 구조 재사용

→ "효과를 보유할 수 있는 상태"까지 구현.

## 3단계 — 효과 선택/적용
보유한 효과 구입 후 적용
현재 적용된 효과 저장
적용된 효과 표시
구매한 효과와 적용된 효과 구분

→ 게임과 무관하게 상점에서 효과를 관리.

## 4단계 — 파티클 효과 실행 시스템
효과를 실제 화면에 표시하는 공통 함수 구현
효과 생성/실행/삭제 관리
특정 이벤트와 연결하지 않고 테스트용 호출만 구현
게임이나 상점 어디서든 호출할 수 있는 구조로 작성

→ 이 단계에서 "효과 자체가 정상적으로 작동하는지" 검증.

## 5단계 — 효과 선택 시스템

이 단계에서 다음 규칙을 만들어 둡니다.

보유 효과 1개
→ 해당 효과 선택

보유 효과 2개 이상
→ 보유 효과 중 랜덤 선택

그리고 특정 효과를 제외해야 하는 경우도 여기서 처리할 수 있습니다.

예:

현재 장착 효과
→ 랜덤 후보에서 제외

## 6단계 — 게임 이벤트 연결

게임의 기존 이벤트에 효과를 연결.
예 콤보 달성
→ playEffect()

특정 콤보
→ playEffect()

→ 효과 시스템과 게임 로직을 분리.

## 7단계 — 이벤트별 효과 규칙 설정

이벤트 자체의 규칙만 정합니다.

예:

정답       → effectType: "correct"
5콤보      → effectType: "combo"
10콤보     → effectType: "combo-special"

그리고 실제 랜덤 선택은 5단계의 공통 시스템이 담당합니다.

즉,

게임 이벤트
    ↓
"어떤 종류의 효과인가?"
    ↓
효과 선택 시스템
    ↓
보유 효과 중 랜덤 선택
    ↓
파티클 실행
