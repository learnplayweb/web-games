function 을를(이름) {
  const 마지막글자 = 이름.trim().at(-1);
  const 코드 = 마지막글자?.charCodeAt(0) - 0xAC00;

  return 코드 >= 0 && 코드 <= 11171 && 코드 % 28 !== 0 ? '을' : '를';
}

# 색 분리




Commit Summary

Implement pattern-based color system and result modal

목적

캐릭터의 내부(fill)에 패턴 기반 색상을 적용하는 기능을 구현한다.

현재 외곽선(stroke)에 적용되는 색상 처리 구조를 내부(fill) 적용 방식으로 변경한다.

---

구현 항목

### 1. 색상 적용 구조 변경

내용

현재 외곽선(stroke)에 적용되는 색상 처리 구조를 패턴 기반 내부(fill) 적용 구조로 변경한다.

세부 조건

* 기존 외곽선 색상 변경 로직은 제거하거나 내부(fill) 적용 방식으로 변경한다.
* 외곽선(stroke)은 항상 기존 색상을 유지한다.
* 내부(fill)에만 색상을 적용한다.
* 캐릭터 전체(머리/상체/하체)에 하나의 패턴이 연속적으로 적용되도록 한다.
* 파츠별로 독립 패턴을 적용하지 않는다.

---

### 2. 색 섞기
색 섞기 결과
├─ pattern
│  └─ pattern-01.svg
└─ gradient
   └─ SVG gradient 설정
   - <linearGradient> <radialGradient>
    - js가 색상, 방향 동적 생성

#### 패턴 적용

내용

패턴 SVG를 이용하여 캐릭터 전체 색상을 생성한다.

세부 조건

* 패턴 파일은 `characters/assets/pattern/` 폴더에서 불러온다.
* 패턴 파일은 `pattern-01.svg`, `pattern-02.svg` ... 형식을 사용한다.
* 패턴는 랜덤으로 1개 선택한다.
* 패턴 SVG 내부의 `color-a`, `color-b`, `color-c` 그룹에 색상을 적용한다.
* 현재 적용 색은 항상 포함한다.
* 보유 색 중 다른 색을 랜덤으로 선택하여 최대 3색까지 구성한다.
* 1색

  * color-a/b/c 모두 같은 색 적용
* 2색

  * 현재 색 2개 영역
  * 새 색 1개 영역
* 3색

  * 세 그룹에 각각 서로 다른 색 적용
* 색상 적용은 그룹 단위로 수행한다.
* 패턴 SVG 자체는 수정하지 않는다.

내용

세부 조건

* 기존 조합 결과 모달 UI를 재사용한다.
* 현재 생성된 패턴 색상을 적용한 캐릭터 미리보기를 표시한다.
* 버튼은

  * 확인
  * 다시 섞기 💎30
* 두 버튼의 배치와 디자인은 조합 모달과 동일하게 유지한다.

## 목표

현재 저장된 캐릭터를 메인 화면과 게임 화면에 자연스럽게 표시한다.

## 요구사항

### 1. 표시 대상

현재 저장된 캐릭터를 표시한다.

이름은 표시하지 않는다.

### 2. 표시 위치

캐릭터는 화면을 가리지 않는 후보 위치 중 하나를 랜덤으로 선택하여 표시한다.

예)

* 좌측 상단
* 우측 상단
* 좌측 하단
* 우측 하단

후보 위치는 UI 요소(시계, 입력 영역, 버튼, 헤더 등)와 겹치지 않도록 미리 정의한다.

게임 시작 또는 화면 진입 시마다 후보 위치 중 하나를 랜덤으로 선택한다.

### 3. 화면별 동작

메인 화면

* 자연스럽게 배치한다.

게임 화면

* 시계와 겹치지 않는 위치에 표시한다.
* 게임 플레이를 방해하지 않는다.

### 4. 애니메이션

기존 캐릭터 애니메이션을 그대로 사용한다.

* 둥실둥실
* 살랑살랑
* 자연스러운 흔들림

### 5. 공통화

캐릭터 표시 기능은 공통 컴포넌트로 구현한다.

향후 다른 화면에서도 동일한 방식으로 사용할 수 있도록 작성한다.

### 제외 사항

아직 구현하지 않는다.

* 클릭 기능
* 표정 변화
* 눈 깜박임
* 콤보 연출
* 정답/오답 연출

## 구현 원칙

* 후보 위치는 CSS 클래스로 관리한다.
* JavaScript는 후보 위치 중 하나만 랜덤 선택한다.
* 기존 UI를 가리지 않도록 배치한다.

변경된 파일만 출력한다.

구현 완료 후 요구사항별 완료/미완료 체크리스트를 함께 보고한다.
